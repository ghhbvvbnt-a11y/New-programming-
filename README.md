# Not Programming — منصة تعليم البرمجة (نسخة Supabase)

منصة تعليمية لتدريس البرمجة، ملف HTML واحد مبني بالكامل على **Supabase** (Auth + قاعدة بيانات Postgres + Storage + Realtime) بدون سيرفر خاص وبدون Build step.

هذه النسخة **جاهزة للاستخدام مباشرة** — تم بالفعل ربطها بمشروع Supabase الخاص بك (الرابط والمفتاح موجودين داخل `index.html`).

## المميزات
- تسجيل دخول للطلاب والمعلم (Supabase Auth).
- كورسات مقسّمة حسب السنة الدراسية ولغة البرمجة.
- محتوى كل كورس: فيديو / ملف PDF / **امتحان** (أسئلة اختيار من متعدد داخل الموقع بتصحيح أوتوماتيكي، أو رابط خارجي زي Google Forms).
- نظام دفع يدوي (فودافون كاش / إنستاباي) مع مراجعة المعلم للإيصالات.
- رسائل مباشرة بين الطالب والمعلم (بحد أقصى 3 رسائل أسبوعيًا للطالب).
- مساعد ذكاء اصطناعي للبرمجة داخل الموقع (عبر Cloudflare Worker كـ proxy).
- دعم 3 لغات: العربية / English / Français، ووضع ليلي/نهاري.
- كل البيانات لحظية (Realtime) — أي عدد من الطلاب والأجهزة يشوفوا نفس التحديثات فورًا.

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع بالكامل (واجهة + منطق الفرونت إند) — الملف اللي بترفعه على الاستضافة |
| `supabase-schema.sql` | سكيما قاعدة البيانات + صلاحيات الحماية (RLS) + الـ Storage buckets — شُغّل بالفعل مرة واحدة على مشروعك، احتفظ بيه كمرجع فقط |
| `ai-proxy-worker-1.js` | كود الـ Cloudflare Worker اللي بيوصل الموقع بالمساعد الذكي |

## الذكاء الاصطناعي داخل الموقع
- من لوحة المعلم → **الإعدادات** → حقل "رابط خادم الذكاء الاصطناعي" → حط رابط الـ Cloudflare Worker بتاعك (بعد نشر `ai-proxy-worker-1.js` عليه).
- الملف ده مستقل تمامًا عن Firebase/Supabase، مفيش أي تعديل عليه.

## ⚠️ أمان
- مفتاح `SUPABASE_ANON_KEY` الموجود داخل `index.html` **آمن إنه يكون ظاهر للعامة** (ده طبيعي في كل مشاريع Supabase) — الحماية الفعلية شغالة بالكامل عبر Row Level Security policies الموجودة في `supabase-schema.sql`.
- **لا تشارك أبدًا** مفتاح `service_role` (لو ظهر ليك في لوحة Supabase) — ده مفتاح سري كامل الصلاحيات ومفيش أي داعي له في هذا الموقع.
