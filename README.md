# Not Programming — منصة تعليم البرمجة (نسخة Supabase)

منصة تعليمية لتدريس البرمجة، ملف HTML واحد مبني بالكامل على **Supabase** (Auth + قاعدة بيانات Postgres + Storage + Realtime) بدون سيرفر خاص وبدون Build step.

هذه النسخة **جاهزة للاستخدام مباشرة** — تم بالفعل ربطها بمشروع Supabase الخاص بك (الرابط والمفتاح موجودين داخل `index.html`).

## المميزات
- تسجيل دخول للطلاب والمعلم (Supabase Auth).
- كورسات مقسّمة حسب السنة الدراسية ولغة البرمجة.
- **مشغّل فيديوهات داخل الموقع** (يوتيوب أو mp4): قائمة دروس، سابق/تالي، تشغيل تلقائي للدرس التالي، سرعة التشغيل، استكمال من آخر نقطة، علامة ✓ للدروس المشاهَدة، وعلامة مائية بإيميل الطالب.
- **محتوى الكورسات محمي من السيرفر**: الفيديو/PDF/الامتحان يظهر فقط للمعلم، أو للكورس المجاني، أو للطالب اللي دفعته اتقبلت.
- محتوى كل كورس: فيديو / ملف PDF / **امتحان** (أسئلة اختيار من متعدد داخل الموقع بتصحيح أوتوماتيكي، أو رابط خارجي زي Google Forms).
- نظام دفع يدوي (فودافون كاش / إنستاباي) مع مراجعة المعلم للإيصالات.
- رسائل مباشرة بين الطالب والمعلم (بحد أقصى 3 رسائل أسبوعيًا للطالب).
- مساعد ذكاء اصطناعي للبرمجة داخل الموقع (عبر Cloudflare Worker كـ proxy).
- دعم 3 لغات: العربية / English / Français، ووضع ليلي/نهاري.
- كل البيانات لحظية (Realtime) — أي عدد من الطلاب والأجهزة يشوفوا نفس التحديثات فورًا.

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع بالكامل (واجهة + منطق الفرونت إند) — الملف اللي بترفعه على الاستضافة |
| `supabase-secure-items.sql` | **مهاجرة الحماية** — تنقل المحتوى لجدول `course_items` المحمي وتصلح ثغرة الدفع. شغّلها مرة واحدة بعد `supabase-schema.sql` |
| `supabase-schema.sql` | سكيما قاعدة البيانات + صلاحيات الحماية (RLS) + الـ Storage buckets — شُغّل بالفعل مرة واحدة على مشروعك، احتفظ بيه كمرجع فقط |
| `ai-proxy-worker-1.js` | كود الـ Cloudflare Worker اللي بيوصل الموقع بالمساعد الذكي |

## الذكاء الاصطناعي داخل الموقع
- من لوحة المعلم → **الإعدادات** → حقل "رابط خادم الذكاء الاصطناعي" → حط رابط الـ Cloudflare Worker بتاعك (بعد نشر `ai-proxy-worker-1.js` عليه).
- الملف ده مستقل تمامًا عن Firebase/Supabase، مفيش أي تعديل عليه.

## مشغّل الفيديوهات
- ارفع الفيديوهات على يوتيوب بوضع **Unlisted** وضع الرابط في المحتوى (نوع: فيديو). Supabase يخزّن الرابط فقط، فلا يستهلك مساحة تُذكر.
- يقبل روابط `watch` و`youtu.be` و`shorts` و`live` وروابط mp4 المباشرة.
- تقدّم الطالب (آخر نقطة + المشاهَد) يُحفظ على جهازه (`localStorage`) وليس في Supabase.

## إرسال الدرجة لولي الأمر
- **تلقائي**: أول ما الطالب يسلّم الامتحان، الموقع بيطلب من الـ Worker (`/notify`) يبعت الدرجة على رقم ولي الأمر المسجّل في حساب الطالب. الـ Worker بيقرأ الدرجة من القاعدة بصلاحيات الطالب نفسه، فمينفعش تتزوّر.
- **المزوّد**: Twilio (SMS أو WhatsApp) أو أي خدمة تانية عن طريق `NOTIFY_WEBHOOK` (Make / n8n / Telegram / بوابة SMS). المتغيرات مشروحة أعلى `ai-proxy-worker.js`.
- **بدون مزوّد (مجاني)**: في تبويب "الدرجات" زرّين `WhatsApp 👪` و`SMS 👪` بيفتحوا الرسالة جاهزة على رقم ولي الأمر، والمعلم يضغط إرسال.
- الإرسال التلقائي بيستخدم نفس رابط الـ Worker المكتوب في الإعدادات (خانة AI server URL). لو فاضي، مفيش إرسال تلقائي.
- رقم ولي الأمر اللي بيبدأ بـ `0` بيتحوّل تلقائيًا لكود مصر `20` (غيّره بـ `COUNTRY_CODE`).

## حماية المحتوى
- المحتوى في جدول `course_items` بسياسة RLS: يقرأه المعلم، أو أي طالب مسجّل إذا كان الكورس مجانيًا، أو من لديه دفعة بحالة `a` (مقبولة) لهذا الكورس.
- الطالب يرى عدد عناصر الكورس المقفول (`icount`) دون الروابط.
- سياسة إدخال الدفعات صارت تسمح للطالب بإضافة دفعة بحالة `p` فقط؛ القبول للمعلم وحده (كانت ثغرة تسمح للطالب بقبول دفعته بنفسه).
- بعد التشغيل، أي كورس أو درس يُضاف من لوحة المعلم يُحفظ تلقائيًا في الجدول الجديد.

## ⚠️ أمان
- مفتاح `SUPABASE_ANON_KEY` الموجود داخل `index.html` **آمن إنه يكون ظاهر للعامة** (ده طبيعي في كل مشاريع Supabase) — الحماية الفعلية شغالة بالكامل عبر Row Level Security policies الموجودة في `supabase-schema.sql`.
- **لا تشارك أبدًا** مفتاح `service_role` (لو ظهر ليك في لوحة Supabase) — ده مفتاح سري كامل الصلاحيات ومفيش أي داعي له في هذا الموقع.
